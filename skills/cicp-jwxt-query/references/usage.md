# 使用详情（渐进披露：仅在需要时阅读）

## 图形化查询面板（WebUI）

无需命令行即可用图形界面查询全部 13 类功能：

```bash
python scripts/webui.py
```

启动后自动打开浏览器 `http://127.0.0.1:8765/`，页面左侧选查询类型与参数、右侧展示结果。
其他方式：`python scripts/webui.py --port 9000`（改端口）、`--no-browser`（不自动开浏览器）。
- 面板复用 `credentials.json` 登录（也可在页面填账号密码覆盖）
- 只监听本机 127.0.0.1，不对外网开放
- 停止服务：运行面板的终端按 Ctrl+C

## 输出格式

### 文本格式（课表类）

按星期和节次排序，每门课程显示节次、课程名、教师、教室、班级、周次。

### JSON格式（课表类，`--json`）

```json
{
  "courses": [{"name": "...", "classes": "...", "teacher": "...", "week": "1-15周",
               "classroom": "...", "weekday": 2, "weekday_name": "星期二",
               "period": "0506", "period_label": "第5-6节"}],
  "count": 8
}
```

教师查询遇到同名冲突时，JSON 额外含 `duplicate_name_warning` 与 `conflict_slots`。

### JSON格式（绩点类）

```json
{"gpa": 2.56, "weighted_avg": 65.7, "total_credits": 40.5, "passed_credits": 38.0,
 "failed_count": 3, "failed_courses": ["法理学(44分)", "大学英语三(45分)"]}
```

## 常见问题

**Q: 登录失败怎么办？**
A: 检查账号密码。脚本会输出具体错误（如"账号或密码错误"）。

**Q: 查询结果为空？**
A: 可能名称不准，或该时段确实无课。教室名不带"三教/一教"前缀（如用 `3-307` 而非 `三教-3-307`）。尝试不填周次/星期查全部。

**Q: 教师查询提示"同名冲突"？**
A: 该校存在同名教师，结果可能合并了多人课表。结合课程名、班级、教室人工确认，或用更精确姓名（含工号）再查。

**Q: 会话超时/登录失效？**
A: 脚本自动检测并重新登录后重试一次，无需手动处理。

**Q: 新学期需要改配置吗？**
A: 一般不需要。脚本会自动探测学期ID、节次模式ID和校历；自动探测失败再手动修改 `jwxt_config.py` 顶部 `CONFIG` 的 `xnxqh`、`kbjcmsid`、`semester_start`。

**Q: 选课监控提醒（E3）？**
A: `--type elective` 查选课轮次是否开放。如需定时提醒，可在豆包内配合定时任务周期性调用本脚本。

## 注意事项

1. 脚本通过 HTTP 直接调用接口，无需浏览器。
2. 登录密码通过页面内置加密算法处理，脚本已实现相同算法。
3. 查询结果与教务系统页面显示一致。
4. 不要把账号密码记录到日志（本地凭证文件除外，权限须为600）。
5. 本人课表按周加载，`--week` 传周次数字（如 3），脚本自动换算为该周周一日期。
