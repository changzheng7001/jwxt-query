# 中警院空教室极速查询

查空教室时**不要**做任何探查或额外请求，直接按用户问的时段跑一条命令，把输出原样呈现给用户（含"空教室 N 间"清单）。

## 唯一动作

```bash
python3 /home/user/.doubao/agent_mode/workspace/.user_skills/cicp-free-room/scripts/query.py [参数]
```

参数（默认=今天当前时段）：
- `--weekday N`  星期（1-7）。用户说"今天/周一/周三"等时按星期填。
- `--period 上午|下午|晚上`。用户没提时段时省略（自动取当前时段）。
- `--cold` 强制重建缓存（提示课程可能变了时用）。

示例：
- 问"今天下午有空教室吗" → `--weekday 今天星期数 --period 下午`
- 问"周三上午" → `--weekday 3 --period 上午`

## 输出

直接把命令输出逐行呈现给用户，不要重新排版、不要补充分析。若命令报错，原样转告错误并重跑一次。

凭证已在脚本顶部，无需用户提供。
